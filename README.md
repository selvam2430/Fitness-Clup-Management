# 🏋️ SELVAMGAIN Fitnees Pro

An interactive and dynamic Fitness Club Management web application designed to streamline gym operations, improve member engagement, and manage daily fitness center activities efficiently.

---

# 🚀 Features
 

### 🏠 Dashboard
- Animated KPI counters
- Recent members activity
- Weekly attendance bar chart
- Today's class schedule
- Live alerts & notifications

### 👥 Members
- Searchable member table
- Filter chips:
  - All
  - Active
  - Expired
  - Trial
- Status badges
- Edit actions

### ✅ Check-In
- Real-time live clock
- Tap-to-simulate attendance scanning
- Dynamic check-in feed updates instantly

### 📅 Schedule
- Full class timetable
- Day-wise filters
- Capacity progress bars
- One-click class booking

### 📈 Reports
- KPI analytics dashboard
- 6-month revenue chart
- Membership plan distribution
- Top performing classes
- Trainer performance ratings

---
